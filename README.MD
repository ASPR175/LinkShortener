# Link Shortener

link shortener with real-time analytics, role-based access, and secure authentication. Designed to scale, handle multiple workspaces, and provide deep insights into link usage.

## Features
- Shorten and manage links (create, edit, delete)
- Real-time graphical analytics
- Multi-tenant workspaces with role-based access( Owner / Admin / Member) permissions
- OAuth authentication with Google & GitHub
- Email-based workspace invitations
- Secure Redis token blacklisting
- Fully responsive UI

## Tech Stack
- Frontend: Next.js, Node.js, React, TypeScript, Zustand for state management, TailwindCSS, Shadcn UI
- Backend: Go (Fiber), REST APIs, Resend
- Database: MongoDB, Redis
- Other tools: Git,Vscode

## Setup
1. Clone the repo
2. Install dependencies
